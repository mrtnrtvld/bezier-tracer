Bézier Tracer

Double-click index.html to open it in your browser. No install or internet connection needed.

Your paths and stroke settings are saved in the browser and come back the next time you
open this same file. The sketch image isn't saved, so load it again each session.
Export SVG > Download .svg saves tracing.svg to your Downloads folder.

Development (auto-reload)

Run `npm install` once, then `npm run dev`. It opens the app at http://localhost:5173 and
reloads the page whenever you save a change. Saved paths are kept separately here from the
double-clicked file, because the browser stores them per address.
